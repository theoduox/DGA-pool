# DGA-Pool 使用说明

[返回中文首页](../README.zh.md) | [English](Usage.md)

## 从哪里开始

只想处理图像或视频，先运行scripts/中的增强入口，使用随附权重即可。想重新训练网络，再看训练入口和configs/。想了解算法细节，阅读src/；想检查安装和程序入口是否正常，再运行tests/。

| 目录 | 放什么 | 怎么使用 |
|---|---|---|
| scripts/ | 可直接运行的命令行入口 | 按任务选择一个脚本，用python -m scripts.模块名运行 |
| src/ | 网络、损失、Gamma搜索、ROI及数据读取等实现 | 被scripts/导入，一般不直接运行 |
| tests/ | 针对性功能检查 | 安装后按需运行；日常处理图像不需要先跑测试 |
| configs/ | JSON参数配置 | 通过入口的--config选择，不包含训练数据 |
| data/ | 运行样例和完整数据的解压位置 | 完整数据分别放在dataset-images/与dataset-videos/ |
| weights/ | 随附的增强权重enhancement_realtime.pth | 由--weights指定；不含分类权重 |

以下路径均相对于项目根目录，即能看到README.md、scripts/和src/的目录。不要进入scripts/或src/后再运行命令。

## scripts：按任务选择入口

| 文件 | 用途 | 输入与输出 |
|---|---|---|
| [scripts/enhance_images.py](../scripts/enhance_images.py) | 处理单张图像或整个目录；默认生成参考图、搜索Gamma并输出原尺寸增强结果，也可只输出网络参考图。 | 图像、增强权重 → PNG和enhancement.json |
| [scripts/enhance_video.py](../scripts/enhance_video.py) | 处理视频或相机输入，后台估计Gamma、前台逐帧LUT增强；包含回放、并排显示和退出控制。 | 视频/相机、增强权重 → MP4和同名JSON |
| [scripts/extract_roi.py](../scripts/extract_roi.py) | 从图像中定位并裁剪熔池ROI，采用轮廓和HSV评分方法。 | 图像 → ROI PNG和roi.json |
| [scripts/train_enhancement.py](../scripts/train_enhancement.py) | 读取配置和训练图像，调用增强训练实现，从头训练或按配置加载初始权重。 | 无标签图像目录 → 每轮权重和config.json |
| [scripts/train_classifier.py](../scripts/train_classifier.py) | 独立训练ConvNeXt-Tiny；支持已有类别目录和CSV子集，不自动划分或增强图像。 | 标注图像、划分、配置 → best.pth、last.pth、training.csv和config.json |
| [scripts/evaluate_classifier.py](../scripts/evaluate_classifier.py) | 加载已有分类权重，输出逐图类别、概率和分类指标；可按CSV选择评估子集。 | 标注图像、分类权重 → predictions.csv和metrics.json |
| [scripts/reproduce_classification.py](../scripts/reproduce_classification.py) | 按案例配置调用分类评估，并与保存的参考指标比较。需要额外的历史图像和分类权重，公开数据包不足以直接运行全部案例。 | 历史材料根目录、案例 → 评估结果和reference_comparison.json |

例如，查看图像增强入口的全部参数：

```powershell
.\.venv\Scripts\python.exe -m scripts.enhance_images --help
```

## src：入口调用的算法实现

| 文件 | 职责 |
|---|---|
| [src/common.py](../src/common.py) | 共享工具：读配置、选择CPU/GPU、查找图像、严格加载模型权重、写JSON。 |
| [src/enhancement/model.py](../src/enhancement/model.py) | EnhanceNetLight网络结构，包括深度可分离卷积、SE模块和曲线迭代；输出中间增强图、最终参考图和曲线参数。 |
| [src/enhancement/losses.py](../src/enhancement/losses.py) | 增强训练的六项损失：颜色、空间一致性、曝光、总变分、色度和光照约束。 |
| [src/enhancement/training.py](../src/enhancement/training.py) | 增强图像读取、模型初始化、损失组合、优化器、学习率调度和训练权重保存。 |
| [src/enhancement/gamma.py](../src/enhancement/gamma.py) | 网络参考生成、Gamma候选网格、灰度MSE比较、窗口采样和LUT校正。 |
| [src/enhancement/stream.py](../src/enhancement/stream.py) | 异步视频调度：收集窗口、提交后台估计、启用最近完成的Gamma，后台忙时跳过新满窗口。 |
| [src/classification/core.py](../src/classification/core.py) | 建立ConvNeXt-Tiny、定义训练/评估预处理、读取类别目录及CSV子集、计算三分类指标。 |
| [src/preprocessing/roi.py](../src/preprocessing/roi.py) | ROI配置、轮廓与HSV评分、裁剪框计算和无有效区域时的处理。 |

这条调用关系可以帮助定位代码：图像入口调用model.py和gamma.py；视频入口再通过stream.py调度；两个训练入口分别调用增强训练实现和分类核心，不是联合训练。

以下`__init__.py`是Python包标识文件，目前为空，供模块导入使用，不是额外算法或运行入口：

[scripts/__init__.py](../scripts/__init__.py), [src/__init__.py](../src/__init__.py), [src/enhancement/__init__.py](../src/enhancement/__init__.py), [src/classification/__init__.py](../src/classification/__init__.py), [src/preprocessing/__init__.py](../src/preprocessing/__init__.py)。

## tests：功能检查

| 文件 | 检查什么 |
|---|---|
| [tests/test_dataset_splits.py](../tests/test_dataset_splits.py) | 检查类别顺序、大小写兼容、CSV子集、重复或缺失标识及错误参数；用临时图像和小模型验证一次训练/评估入口调用。 |
| [tests/test_video_demo.py](../tests/test_video_demo.py) | 检查视频帧率、显式覆盖、输出尺寸、等待/启用状态及Q/Esc/关闭窗口退出。使用合成短视频和模拟GUI事件，不需要连接相机。 |

运行现有全部13项检查：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

这些检查验证程序行为，不重新训练论文模型，也不用于验证论文分类准确率。视频检查会在outputs/video_demo_tests/生成小型测试文件；部分GUI行为通过模拟事件检查。

## configs：配置文件

| 文件 | 用途 |
|---|---|
| [configs/enhancement_train.json](../configs/enhancement_train.json) | 增强网络常规训练配置。 |
| [configs/gamma_realtime.json](../configs/gamma_realtime.json) | 当前图像/视频默认配置：首轮Gamma范围1.1–3.0，4秒窗口、15张采样。 |
| [configs/gamma_paper.json](../configs/gamma_paper.json) | 论文描述的初次Gamma搜索范围0.1–5.1。 |
| [configs/roi_historical.json](../configs/roi_historical.json) | 轮廓/HSV ROI提取参数。 |
| [configs/classification_historical.json](../configs/classification_historical.json) | 已恢复历史分支参数：30轮、momentum 0.9、每7轮衰减学习率。 |
| [configs/classification_paper.json](../configs/classification_paper.json) | 论文描述参数示例：50轮、momentum 0.5、每10轮衰减；与历史配置分开提供。 |
| [configs/enhancement_install_check.json](../configs/enhancement_install_check.json) | CPU一轮增强训练，用于安装检查。 |
| [configs/classification_install_check.json](../configs/classification_install_check.json) | 一轮分类训练，用于安装检查。 |
| [configs/classification_reproductions.json](../configs/classification_reproductions.json) | 历史分类案例所需的相对路径、预处理和参考指标。 |

后续Gamma局部搜索在前次Gamma±0.5内进行，下界至少为0.1。两套分类配置记录的训练设置不同，使用时应按实验目的选择。

## 安装与数据位置

推荐Python 3.12。先安装[uv](https://docs.astral.sh/uv/getting-started/installation/)，再进行CPU安装：

```powershell
uv venv --python 3.12 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt --torch-backend cpu
```

随附样例在data/examples/。完整图像ZIP顶层为dataset-images/，视频ZIP顶层为dataset-videos/；两包均解压到data/下，不合并、不覆盖文件。代码包中的两个空目录只含.gitkeep占位。图像实验可不下载视频包。

图像索引与四套历史划分位于data/dataset-images/；不设默认划分。详细内容、类别与引用见下载包内README.md和splits/中的CSV文件；也可先看[代码区数据说明](../data/README.md)。

## 常用运行方式

### 图像增强

三张样例无需重新训练：

```powershell
.\.venv\Scripts\python.exe -m scripts.enhance_images --input data/examples/images --output outputs/examples/enhanced --weights weights/enhancement_realtime.pth --device cpu
```

输入可换为自己的单张图像或目录，输出目录应位于输入目录之外。默认逐图估计Gamma，不把目录中的图片组成时间窗。输出保留相对目录，文件名追加.png，并记录enhancement.json。

加上`--mode reference`可只输出224×224网络参考图；默认Gamma模式输出原尺寸最终增强图。原图、ROI和预期结果见[样例目录](../data/examples/)。

### 视频增强

```powershell
.\.venv\Scripts\python.exe -m scripts.enhance_video --source data/examples/videos/normal_video.mp4 --output outputs/examples/video_comparison.mp4 --weights weights/enhancement_realtime.pth --realtime --side-by-side --show --device cpu
```

--realtime按源帧率回放文件；--side-by-side保存并排比较；--show打开预览。按Q、Esc或关闭窗口退出；省略--show可无界面运行。不传--side-by-side时保存干净增强视频。--preview-scale只影响预览/比较尺寸，--fps可覆盖有效帧率。

默认4秒窗口、15张采样，初始Gamma为1；后台计算完成后更新，期间沿用最近可用值。忙时跳过新满窗口，末尾不足一窗不估计新参数，不回写已输出帧。此入口不设置相机曝光，也不自动裁ROI。--source 0可选择默认相机，不传--realtime；发布准备期间未接测真实相机。

### ROI提取

```powershell
.\.venv\Scripts\python.exe -m scripts.extract_roi --input data/examples/originals --output outputs/roi --config configs/roi_historical.json
```

默认448×448裁剪，边缘处可能更小，不补边。找不到轮廓的图像记录为no_roi并跳过；裁剪框见roi.json。

### 增强网络训练

自行准备RGB图像目录，例如按原项目条款获取的[SICE](https://github.com/csjcai/SICE)。图像可嵌套，不需要状态标签；SICE训练图像不随本项目提供。将下面占位路径替换为实际目录：

```powershell
.\.venv\Scripts\python.exe -m scripts.train_enhancement --images "path/to/training/images" --output outputs/enhancement --config configs/enhancement_train.json
```

默认224×224输入、batch 8、200轮，每轮保存权重。--cpu强制CPU；不接入分类损失。只检查能否训练时，可改用configs/enhancement_install_check.json进行一轮检查。

### 分类训练与评估

分类器与增强网络独立训练。每个图像根目录下包含excessive、insufficient、normal三个类别目录（也兼容首字母大写），索引依次为0、1、2。先确定使用原图、ROI还是预先增强图，每个方案单独训练；程序不自动增强或重新划分。

下载图像包后，可显式选择一套历史CSV名单。以下是实际训练命令，不是只读检查；--init imagenet在未缓存时会下载预训练参数，--init random则随机初始化：

```powershell
.\.venv\Scripts\python.exe -m scripts.train_classifier --train data/dataset-images/images/original --val data/dataset-images/images/original --split-file data/dataset-images/splits/historical_original_80_10_10.csv --train-subset train --val-subset val --output outputs/classifier --config configs/classification_historical.json --init imagenet
.\.venv\Scripts\python.exe -m scripts.evaluate_classifier --images data/dataset-images/images/original --split-file data/dataset-images/splits/historical_original_80_10_10.csv --subset test --weights outputs/classifier/best.pth --output outputs/evaluation --preprocessing center_crop
```

训练与验证可以使用同一图像根目录，但选中的CSV成员不能重叠。也可以分别提供已有训练/验证目录，不传CSV。上述名单只是用法示例，不是项目默认划分。评估需要对应方案的分类权重；本项目随附的是增强权重，不能用它替代分类权重。

center_crop为Resize(256)+CenterCrop(224)，resize为直接缩放到224×224，均使用ImageNet归一化。评估输出的混淆矩阵按行表示真实类别、按列表示预测类别，另有准确率、各类precision/recall/F1和macro F1。

### 历史分类案例复核

下面的--list只显示案例，不加载权重或图像：

```powershell
.\.venv\Scripts\python.exe -m scripts.reproduce_classification --list
.\.venv\Scripts\python.exe -m scripts.reproduce_classification --source-root "path/to/historical/materials" --case divided_val --device cpu
```

第二条需要指定额外历史材料，路径由configs/classification_reproductions.json描述。--case支持scheme1、scheme2、scheme3、scheme4、divided_val及all。没有这些材料时可跳过此入口，不影响图像/视频增强、重新训练或普通分类评估。
